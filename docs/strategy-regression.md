# MACD/WR 层级策略回归验证

## v3 规则

`macd-wr-mtf-2026.08.3` 不再用日/周/月 1:2:3 加权投票决定大方向：

1. 月线 MACD 锚定大结构；月线处于零轴切换区时才由周线确认方向。
2. 周线 MACD 判断趋势延续或周级调整。
3. 月/周线零轴上多次金叉后转弱、价格-DIF 顶背离或 DIF 第二顶部会阻断新增买入并武装退出风险。
4. WR 只确认具体时机：上涨结构且无顶部风险时，日线 WR 深度超卖形成入场；顶部风险成立后，日/周 WR 超买确认退出。

当前桌面实时建议在上述个股规则之后增加大盘默认门控和按需板块门控。历史回归仍只验证个股 MACD/WR 核心，不能把当前大盘或板块状态回填到历史日期。三层共振回测必须在每个评估截面只使用当日已经完成的个股、大盘和板块 K 线，并作为独立策略版本统计，详见 [market-sector-confluence.md](market-sector-confluence.md)。
5. 形成中的周/月 K 永不进入正式信号；收盘后生成状态，最早次日开盘执行。

Advice 将入场观察映射为无持仓买入/有持仓加仓，将退出观察映射为有持仓卖出/无持仓回避。5/10/20 日历史命中率只在同规则样本存在时使用，否则显示明确标注“非概率”的情景分。

## 数据与方法

- 数据：BaoStock 公开历史前复权日 K，`2018-01-01` 至 `2026-08-15`，实际最新交易日 `2026-08-14`。
- 预先固定样本：20 只，覆盖消费、金融、新能源、医药、券商、资源、公用事业和制造。
- 6 月信号观察：`2025-06-01` 至 `2025-06-30`。
- 完整 walk-forward：`2025-06-01` 至 `2026-06-30`。
- 每个截面最多使用此前 800 个交易日，至少 520 个交易日预热；单边成本 10 bps。
- 同一信号状态连续期间只记录首次触发；状态离开后再次进入可形成新信号。
- 报告版本：`macd-wr-walk-forward-2026.08.3`；hash 是规范化 JSON 的变更指纹，不是数字签名。

## 结论

回归证明 v3 规则在历史截面中可确定执行、可计算成本且没有未来函数，不证明稳定超额收益。20 只样本中既有宁德时代、隆基绿能等正收益，也有贵州茅台、平安银行、中国神华等亏损；即使绝对收益为正，海康威视、美的集团、中信证券和紫金矿业也跑输基准。空仓产生的正超额（如比亚迪）不代表择时盈利，只表示区间没有持仓。实盘前仍须更新行情、检查成交条件并自行决策。
