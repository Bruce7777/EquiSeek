# 负责任使用与合规边界

求衡是一个本地优先的智能投研与软件工程项目，用于整理公开信息、验证明确规则、比较情景并保留研究证据。它不是券商，不连接证券账户，不自动下单，也不承诺收益。

## 如何理解输出

输出可能同时使用历史行情、确定性计算、用户配置的规则和模型辅助解释，因此可能不完整、过时或错误。采取行动前，应核验原始来源、时间戳、前提假设、计算方法和失效条件。回测及模拟结果不能证明未来表现。

## 数据、模型与本地信息

用户和运营者应自行遵守行情数据授权、模型服务条款、依赖许可证及适用的隐私义务。API 凭证不得提交到仓库。持仓数量、成本、日期、备注和生成的工作区可能属于敏感个人信息，宜采用本地存储、最小权限、加密和明确的保留策略。

## 对外或商业化运营

开源许可证和本地部署不会自动产生监管豁免。若计划面向公众收费，或提供涉及具体证券、买卖时机的个性化服务，应针对实际运营地区取得专业意见，并至少评估：

- 证券投资咨询等相关业务许可和人员资质；
- 客户适当性、风险揭示、合同、投诉处理和审计留痕；
- 行情、新闻、研究内容及模型输出的使用权；
- 隐私、网络安全、数据跨境及生成式人工智能治理义务；
- 营销表述、业绩展示、利益冲突和人工复核机制。

本文仅说明产品边界，不构成法律、税务或投资建议。求衡的部署者和使用者仍需自行对决策与合规负责。
