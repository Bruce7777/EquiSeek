# 个股—大盘—板块共振分析

EquiSeek 的单股策略不再孤立地读取个股 MACD/WR。每次分析会用相同数据源自动加载默认大盘，用户还可以按需加载行业指数代理。大盘和板块使用与个股相同的月线 MACD 锚定、周线调整/顶部风险、日线 WR 时机规则。

| 个股市场 | 默认基准 |
|---|---|
| 上海主板 | `000001.SH` 上证综指 |
| 深圳主板 | `399001.SZ` 深证成指 |

## 板块代理

BaoStock 模式选用能够取得多年历史的中证行业指数，而不是近期历史较短的 ETF：

| 行业组 | 指数代理 |
|---|---|
| 半导体、芯片、电子、软件、计算机、AI | `000935.SH` 中证信息技术 |
| 医药、医疗、生物 | `000933.SH` 中证医药卫生 |
| 银行、证券、保险、金融 | `000974.SH` 中证800金融 |
| 食品、白酒、农业、零售、主要消费 | `000932.SH` 中证主要消费 |

这些代码来自中证行业指数体系；指数定义与编制方法以[中证行业指数编制方案](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/000841_Index_Methodology_cn.pdf)为准。信息技术、可选消费和能源示例可查看中证官方 factsheet：[000935](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/000935factsheet.pdf)、[000931](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/000931factsheet.pdf)、[000928](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/000928factsheet.pdf)。代理关系会在客户端直接显示，不把它伪装成精确行业归属。

## 决策规则

1. 个股没有形成买入/加仓候选时，共振过滤器不会制造买点。
2. 个股形成候选但大盘看空或不可用时，行动降级为等待/持有。
3. 个股和大盘同步、板块未加载时，只标记“初筛通过 · 待板块确认”。
4. 已加载板块也同步时，标记“三层共振 · 优先候选”，并对综合置信度做有上限的正向调整。
5. 已加载板块背离或不可用时，关闭积极买入门。
6. 减仓和卖出属于风险动作，不会因为大盘或板块上涨被取消。

规则场景分、置信度调整和“三层共振”都不是收益概率，也不保证后续上涨。

## 数据与成本

- 大盘随单股分析默认请求；板块只有点击后才请求。
- 指数固定使用不复权日线；Tushare 对指数使用 `index_daily`，对基金使用 `fund_daily`，接口定义以 [Tushare 数据接口文档](https://tushare.pro/document/2?doc_id=17)为准。
- 行情进入本地 SQLite 缓存，按提供方、代码、复权口径和日期隔离；再次分析只补缺口。
- 加载板块后本地重算确定性建议，不自动再次调用 DeepSeek。

## 当前限制

- 行业标签到指数是可解释的关键字映射，不等同于证券公司的正式行业分类服务。
- 未知行业由用户手动选择；系统不会猜测。
- 回测现有核心仍以个股 MACD/WR 为主。要评估“当日可见的大盘/板块共振”必须为每个历史截面同步重算三层信号，不能用今天的上下文回填过去；后续应作为独立回测版本实现。
