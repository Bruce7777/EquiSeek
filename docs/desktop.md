# EquiSeek A 股投资研究桌面版

当前产品客户端位于 `apps/desktop`，使用 Electron + React 实现。`make desktop` 启动的就是这套浅色、无登录的 Agent 工作台；旧 PySide/Qt 暗色客户端仅由 `make desktop-legacy` 启动，不再是默认入口。

桌面版默认使用无需 Token 的 BaoStock 公开历史日线。也可以使用自己的 Tushare Token，或选择明确标记为“非真实行情”的离线模拟数据。全部指标、投资动作和方向情景在本地确定性计算；可选模型用于解释和编排，不能覆盖本地证券规则证据。

## 从源码运行

要求 Python 3.12、[uv](https://docs.astral.sh/uv/)、Node.js 22+ 和 npm。

```bash
make desktop-install
make desktop
```

默认股票为 `600050.SH`。Electron 研究页接受 `600519.SH`、`000001.SZ` 和 `.BJ` 形式；北交所行情需使用 Tushare。

## 数据源

- `公开历史数据（BaoStock，无需账号）`：默认，无 Token，沪深真实历史数据；依赖上游网络和服务可用性。
- `Tushare 真实行情`：可选，需要与 DeepSeek Key 完全独立的 Tushare Token；在 Electron“设置”中保存。
- `离线模拟数据`：无需网络，不是任何真实证券；用于体验和测试。

如果选择 Tushare 但尚未配置它自己的 Token，客户端会解释 DeepSeek Key 与行情凭据的区别，并让用户改选 BaoStock 或离线模拟，而不是直接终止分析。北交所真实行情仍需支持该数据的行情源；离线模拟不能作为真实行情替代品。

复权可选不复权、前复权和后复权。同一报告会显示来源、截止日期、复权、样本数和指标公式版本。

## 决策账本

完成的个股研究会写入本机 `run-history.json`，研究页左侧“决策账本”可以回看当时的动作、参考收盘价、数据截止日与完整报告。联网打开研究页或手动刷新时，应用会按原行情源、证券代码和复权方式读取最新收盘价；Tushare 记录继续由 Electron 主进程从系统凭据仓临时注入 Token，Token 不会写进账本或报告。

账本中的“假设结果”只描述规则动作从当时参考价到最新同口径收盘价的方向变化；等待动作只显示价格变化，防守动作显示规避下跌的反向效果。它不代表用户真实下单、成交价格、交易成本或账户收益。离线模拟记录不会伪装成真实市场表现，行情刷新失败时保留上次结果并显示异常原因。

真实行情默认保存在 `~/.equiseek/user-data/market-data.sqlite3`。缓存主键为
`source + symbol + adjustment + trade_date`，BaoStock 与 Tushare、前/后/不复权数据绝不
混用；扩大日期范围时只补齐未覆盖区间，并用一个重叠交易日检测复权历史重构。发现变化时
只重建对应单一序列。无交易日区间也会记录覆盖状态，避免周末和节假日重复请求。离线模拟
数据不会进入真实行情库。可设置 `EQUISEEK_MARKET_CACHE_PATH` 改变路径，或把
`EQUISEEK_MARKET_CACHE_ENABLED=false` 作为故障排查时的临时禁用开关。

每次分析都会建立一个持久化工作计划：行情、全量指标、多周期时机、投资决策、可选持仓动作、事实摘要、可选模型解释、输出门禁。桌面端“工作计划”页签实时显示阶段状态；每个阶段写入独立 `input/output/logs/tmp` 目录，计划保存在 `.state/plan.json`。模型失败会明确降级为本地结论，不会把整个分析误报为失败。

单股分析还会并行运行 `market-context-agent`：按证券市场自动选择基准指数，以同一行情提供方和 BFQ 口径默认展示大盘 K 线+MA、MACD、WR 及月/周/日趋势。板块页初始不拉行情，用户点击“加载板块指标”后才读取中证行业指数代理并利用本地缓存补缺口。个股形成买入/加仓候选但大盘不同步时会降级；板块已经加载后也必须同步才标记“三层共振 · 优先候选”。卖出和减仓风险动作不会因为大盘上涨被取消。完整映射、规则和限制见[个股—大盘—板块共振分析](market-sector-confluence.md)。

桌面研究工作区默认位于用户目录下的 `~/.equiseek/research-workspaces`，因此从 Finder、开始菜单或任意当前目录启动都可写。需要迁移存储位置时可设置 `EQUISEEK_RESEARCH_WORKSPACE_ROOT`；路径支持 `~` 展开。

## DeepSeek

优先使用已有环境变量：

```bash
export DEEPSEEK_API_KEY="your-key"
make desktop
```

也可以在“连接设置”保存 Key，选择 `deepseek-v4-flash`（默认、快速经济）或 `deepseek-v4-pro`（复杂解释能力更强、费用更高），并使用“验证 DeepSeek 连接”检查凭据与所选模型是否可用。模型选择保存在普通本地偏好设置中，手工凭据则进入 macOS Keychain 或 Windows Credential Manager，绝不进入普通设置文件。研究分析、求衡投研助手 和连接测试统一使用当前选择；无 Key、关闭 AI 或 API 失败时，软件自动使用本地规则摘要。HTTP 状态和经过脱敏的服务端错误会显示在 AI 整理页或连接测试结果中。可用模型以 [DeepSeek 官方模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing) 为准。

## 指标

当前公式版本 `canonical-cn-2026.08.1`：MA 5/10/20/30/60、MACD 12/26/9、KDJ 9/3/3、RSI 6/12/24、ATR 14/20、BOLL 20/2、WR 6/10。它是透明基线，并不宣称与任意版本的同花顺/东方财富永久逐点一致。

## 多周期 MACD/WR 策略状态

- 从统一复权日 K 按自然周、自然月聚合；形成中的周/月 K 会显示但不进入正式 MACD、
  WR、背离或双峰信号，并同时标注“决策截止日”和“最新可见日期”。
- MACD 使用明确层级：月线锚定大方向，周线判断趋势延续或周级调整，日线只辅助执行；日线波动不能覆盖月线大结构。方向分只用于候选排序和情景校准，不再作为方向投票器。
- WR 采用项目正向 `0–100` 口径：`>=80` 超卖、`>=85` 深度超卖、`<=20` 超买；这与 TA-Lib 的 `-100–0` 显示口径互为符号转换。
- 上涨结构且无高周期顶部风险时，日线 WR 进入 `>=85` 深度超卖区触发无持仓“买入”或有持仓“加仓”；月/周线出现零轴上多次金叉后转弱、顶背离或第二顶部时先武装退出风险，日线或周线 WR `<=20` 再确认具体卖出窗口。
- “投资结论”页把上述过程渲染成五级决策链和月/周/日状态矩阵，不再显示原始 Markdown；事实、AI、持仓和计划页使用 Markdown 富文本渲染。
- 图表可在日、周、月间切换，并可同时选择 1–3 个指标。MA/BOLL 叠加主图，MACD/KDJ/RSI/ATR/WR 使用独立量纲副图；周/月由同源日 K 本地聚合，不增加行情请求。MACD 按标准“两线一柱”展示：DIF 快线、DEA 慢线和以零轴为基准的红色正柱/绿色负柱，指标公式没有因展示调整而改变。
- 语言模型不计算或改写信号。

## 投资结论与预测

“投资结论”固定在研究主体右侧的核心决策区，并在分析完成后默认打开，显示动作、规则置信度、动作参考区、失效条件和 5/10/20 交易日方向。左侧集中展示指标卡、大盘/板块共振和个股图表，避免最重要的动作结论落到页面右下角。足够历史中存在同类信号时显示无未来函数“历史同条件命中率”及样本数；没有可靠样本时显示 `scenario_score` 上涨情景分、明确标注“非概率”且不提供预期收益。ATR 区间用于波动和失效控制，不是目标价。

## 持仓、自选与候选池

“持仓与自选”可在本地维护股票、行业标签、数量、成本、建仓日和备注。默认文件为 `~/.equiseek/user-data/portfolio.json`，以原子写入且限制为用户读写。数量、成本、日期和备注不发送给 DeepSeek，也不记入普通 Agent 事件。行业标签用于生成不含持仓财务信息的宏观行业映射。

持仓结果会计算建仓后峰值、峰值回撤、回本距离、持仓天数、退出优先级和下一复核触发。
用户填写的行业标签通过透明关键字表关联资本三流/成本转嫁行业视图；未填写或无法识别时
保持“未映射”。宏观只对技术置信度作有上限的加减，绝不把 MACD/WR 卖出改成买入。

“扫描候选池”只对用户本地持仓+自选集合进行同规则排序，桌面端单次最多 50 只。持仓显示加仓/持有/减仓/卖出，自选显示买入/等待/回避；候选表分别显示技术/综合置信度、市场共振优先级、宏观调整以及 20 日历史命中率或非概率情景分。趋势同步会通过市场置信度调整进入排序，但不把规则分伪装成收益概率。它不声称已扫描未加入列表的全市场股票。

## 求衡投研助手 对话

主窗口“求衡投研助手”页面是策略、候选池、个股研究、宏观快照和持仓解释的统一长任务入口。页面左侧只保留研究对象、对话和输入，右侧用“过程 / 成果 / 上下文”展示工具步骤、Markdown 报告、活动 Skill 和隐私边界。输入框使用 Enter 发送、Shift+Enter 换行；页面内发起个股研究或候选筛选不会再跳到其他页面。

每次通用请求进入有界 Lead Agent 循环。它可以渐进启用 Skill，并从组合快照、当前证据、宏观联网研究、个股研究、候选筛选、网页搜索和工作区工具中选择下一步。DeepSeek 只生成严格结构化的下一步动作；没有 Key 或关闭 AI 时，本地规划器通过相同的授权边界执行。Agent 不能发明工具或访问工作区外的任意文件，但可以在用户明确选择的工作区内请求持久 Shell、读取、写入和精确编辑；执行前仍经过参数校验、路径约束和平台沙箱门禁。

每次运行在持仓文件同级的 `investment-agent-workspaces/<run-id>/` 保存状态、配对工具事件和 `investment-agent-report.md`。凭据、持仓数量、成本和备注不会写入这些文件。已有运行文件可审阅和备份；当前版本不会在应用进程被强制终止后自动续跑顶层循环。

输入器下方可直接选择“自动选择 Skill”或某个内置/用户 Skill。用户 Skill 会标记为“我的 Skill”，也仍可用 `/skill-name 问题` 显式指定；显式选择后 Lead Agent 不会暗中再追加另一个入口 Skill。平台行情、指标计算、证券事实和风险护栏属于不可替换的固定研究流水线，会在 Trace 中与用户 Skill 分开标识。

工作区默认是 `~/.equiseek/user-data/investment-agent-workspaces`。点击输入器下方的工作区按钮，可以选择其他现有文件夹、恢复默认值或在 Finder 中打开；选择结果保存在本机普通设置中。每轮仍在根目录下创建唯一子目录，避免不同任务互相覆盖。

右侧 `Trace` 会把外层 Agent 与内层证券研究计划合并展示，包括目标识别、实际 Skill/provider/version、工具选择理由、行情来源与截止日、指标公式版本、研究子任务、月/周/日 MACD 与 WR 五级门控、动作映射、买入触发/失效条件、价格情景和输出护栏。双击带证据的步骤可打开对应 `result.json`；“成果”中还会生成 `investment-agent-trace.md`。这是可审阅的过程和证据摘要，不是模型隐藏思维链。

联网网页搜索是独立的可选能力。在“连接设置”保存 Tavily API Key，或设置 `TAVILY_API_KEY`；未配置时 Agent 会明确报告无法执行网页搜索，绝不把本地知识或宏观历史快照标成实时搜索结果。Tushare、Tavily 和 DeepSeek 的凭据互不替代。

具体持仓动作仍要求当前证券证据。回答读取规则动作、月/周/日 MACD、WR、大盘/板块共振、宏观行业叠加、收益率、回撤、下一触发和失效条件；模型不得修改本地动作、置信度、区间或失效条件，服务异常或回答偏离规则会自动回退。

线程记录保存在持仓文件同级的 `conversations/`，按证券隔离；旧对话超过阈值后压缩为摘要并保留最近 turn。长期记忆只保存用户明确表达的风险类型、投资周期、最大回撤、偏好/回避板块和策略偏好。持仓数量、原始成本、备注、证券代码、本地文件路径和密钥不会进入长期偏好。线程和记忆文件使用私有权限、大小与结构校验；损坏记录不会被自动覆盖，页面会提示确认重置。清空当前对话前需要二次确认，只删除当前线程，不删除长期偏好。

用户 Skill 默认放在 `~/.equiseek/user-data/skills/<name>/SKILL.md`，也可在“连接设置”指定其他目录。输入 `/name 问题` 可显式激活；同名用户 Skill 覆盖内置版本。取消“启用内置投资 Skill”后，工作区只加载用户自己的 Skill。Skill 不能扩张工具或网络权限，也不能覆盖平台级证券证据和风险护栏。

候选筛选 Skill 可声明受限的 `strategy.json` 资源。复制仓库内的示例后即可使用：

```bash
mkdir -p ~/.equiseek/user-data/skills
cp -R examples/user-skills/steady-long-term ~/.equiseek/user-data/skills/
```

然后在求衡投研助手 输入 `/steady-long-term 筛选候选池`。页面会用该 Skill 的最低置信度、候选分、允许动作/方向、市场买入闸门、行业和证券排除项过滤本地持仓+自选池，再按置信度、候选分、市场/宏观调整和行业偏好权重排序；结果表显示策略分与实际策略名称。`max_results` 只能为 1–50。

`strategy.json` 是声明式数据，不执行 Python、Shell 或网络脚本。未知字段、未知 schema、越界权重、卖出/减仓/回避动作、非法证券代码或未声明资源都会拒绝激活。平台还会先执行不可替换的基础安全层，退出候选和卖出类动作不会因为用户 Skill 再次进入买入候选。关闭内置 Skill 后，普通“扫描候选池”按钮不会暗中回退到内置策略，须用 `/你的-skill 筛选候选池` 显式选择。当前 DSL 只控制已有本地候选结果的过滤和排序，不能创造新指标、扫描全市场或替换 MACD/WR 信号计算。

为兼顾咨询能力与隐私，远端模型只接收压缩对话、明确偏好和收益率、当前价、回撤等最小化派生证据。必须注意：收益率与当前价的组合可能被用于推算大致成本；不接受这种派生风险时，应在连接设置中关闭 AI，Agent 仍可使用本地规则能力。

## 策略回测

完成一次股票分析后可点击“策略回测”。执行前可设置评估起止日、单边交易成本和 1–250 交易日范围内的最多 8 个后验观察周期；默认仍是 10 bps 和 5/10/20 日，不改变 MACD/WR 策略阈值。

规则在每个历史交易日只能看到当日及之前的数据，收盘后生成状态，最早在下一交易日开盘执行。结果工作台包含摘要、分周期信号统计、交易明细和信号明细，同时输出策略/基准/超额收益、胜率、最大回撤、平均/中位交易收益、利润因子和持仓暴露。用户可主动导出带 SHA-256 摘要的完整 JSON 或 UTF-8 BOM 信号 CSV；导出不包含凭据、持仓成本或备注。

为控制桌面端耗时，每日截面使用最近 800 个交易日，足以提供约 36 个月线观测。真实 2025 年 6 月回归证据见 [strategy-regression.md](strategy-regression.md)。

## 宏观投资研究

“宏观研究”会动态发现人民银行、国家统计局、国家外汇管理局和财政部的最新发布，抓取官方正文，以固定口径更新 25 项月度/累计核心指标，再与 7 项仍处在最新官方统计期的 GDP、居民收入、工业利润等低频指标合成 32 项快照。采集截止日表示本轮已经检查官方发布，不会冒充每项指标的统计期；页面会逐项展示真实统计期和原文链接。只有完整性与官方时效门禁同时通过，系统才会重算资本三流、成本转嫁、长期配置和行业结论。网络失败时仅可回退到本机最近一次完整联网快照，首次失败不会把陈旧内置基线包装成当前结论。设置 `EQUISEEK_MACRO_DATA_PATH` 仍可加载同结构的受控本地数据。完整口径和来源见 [macro-analysis.md](macro-analysis.md)。

## 测试和构建

```bash
make desktop-smoke       # sidecar self-test + Electron lint/typecheck/Vitest
make desktop-build       # 当前平台未签名解包应用
make desktop-package     # macOS 未签名 ZIP / Windows 未签名 Squirrel，位于 apps/desktop/out/make/
```

PyInstaller sidecar 和 Electron 产物必须在目标架构原生构建。`desktop-package` 和 GitHub Actions 会冻结 Python sidecar、执行其自检，再把它作为 Electron Resource 打进应用。普通 `desktop.yml` 覆盖 macOS arm64、macOS x64 和 Windows x64 的未签名安装验证；手动 `desktop-signed.yml` 使用受保护的 release environment 生成并验证签名产物。证书配置与发布门禁见 [releasing-desktop.md](releasing-desktop.md)。

旧 Qt 客户端的回归和打包命令统一使用 `desktop-legacy-*` 前缀，详见项目主 [README](../README.md#旧-qt-客户端)。

对应字段、行为和打包流程由自动化测试与桌面 smoke 覆盖；公开仓库不包含内部迭代过程记录。

## 安全与用途
