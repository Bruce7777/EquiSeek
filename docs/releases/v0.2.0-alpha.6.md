# EquiSeek v0.2.0-alpha.6 — 未签名 Alpha

这是面向早期试用者的未签名桌面预发布，不经过 Mac App Store 或 Microsoft Store，也没有 Apple Developer ID、Apple 公证或 Windows Authenticode 签名。

本版深化了投研 AI 助手的 Agent Harness。执行计划现在区分运行时与模型所有权，始终限制为最多一个进行中项目；模型首步只接收已晋升工具的完整定义，需要时通过 `tools.search` 按用途或名称发现 Deferred Tool，且晋升不能扩大既有权限。连续使用完全相同的工具和参数会在第 3、5、8 次收到分级提醒，但不会仅因重复而被阻止；未知或未晋升工具仍会在执行前失败关闭。

大型工具结果会完整保存在当前 Run 的 `.state/tool-results`，模型只接收有字符预算的摘要、预览、相对路径、大小和真实文件 SHA-256，并可通过只读 `tool_results.read` 安全分页回读。路径穿越、符号链接和缺失文件均会被拒绝。计划、工具晋升、循环提醒、模型请求以及工具调用统一进入 append-only 事件日志，运行检查器和成果 Trace 可以定位对应事件序号，而不展示模型隐藏思维链。

## 下载

- Apple Silicon Mac（M1/M2/M3/M4 等）：`EquiSeek-macOS-arm64-0.2.0-alpha.6-unsigned.zip`
- Intel Mac：`EquiSeek-macOS-x64-0.2.0-alpha.6-unsigned.zip`
- Windows 10/11 x64：`EquiSeek-Windows-x64-0.2.0-alpha.6-unsigned-Setup.exe`
- 完整性校验：`SHA256SUMS`

## 安装与首次配置

macOS：解压后将 EquiSeek 拖入“应用程序”。首次启动请按住 Control 点击应用并选择“打开”；如果仍被拦截，请前往“系统设置 → 隐私与安全性”确认“仍要打开”。系统仍可能因企业策略禁止未签名软件。

Windows：运行 Setup.exe 后可能看到 Microsoft Defender SmartScreen 警告。确认文件来自本仓库并核对 SHA-256 后，可选择“更多信息 → 仍要运行”。企业管理设备可能禁止绕过。

需要大模型动态语言理解时，在投研助手的无 Key 提示中点击“前往设置配置”，输入用户自己申请的 DeepSeek API Key 并选择“保存并启用”。Key 只保存在当前设备的操作系统安全存储中。未配置 Key 时，应用会明确使用本地固定规则，不会冒充大模型回答。

## 安全与使用边界

- 不要从第三方转载站下载；只使用本 Release 的资产。
- 安装前请用 `SHA256SUMS` 核对文件完整性。
- 安装包不包含维护者或用户的 API Key、凭据文件、持仓、决策账本或运行工作区。
- 当前行情研究范围为中国内地 A 股及已支持的境内指数、基金；全球市场尚未接入。
- 本项目是研究与教育工具，不构成个性化投资建议、收益承诺或代客交易服务。
- 详细系统拦截提示与安装步骤见[未签名桌面版安装指南](https://github.com/Bruce7777/EquiSeek/blob/main/docs/installing-unsigned-desktop.md)。

This unsigned desktop alpha deepens the investment assistant's Agent Harness with revisioned plan ownership, policy-bounded deferred tool discovery, advisory repeat-call reminders, bounded observations with verified paginated readback, and event-referenced traces.
