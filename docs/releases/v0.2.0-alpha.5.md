# EquiSeek v0.2.0-alpha.5 — 未签名 Alpha

这是面向早期试用者的未签名桌面预发布，不经过 Mac App Store 或 Microsoft Store，也没有 Apple Developer ID、Apple 公证或 Windows Authenticode 签名。

本版修正首次使用时对“大模型是否真的在工作”的表达：安装包不内置任何 API Key；未配置用户自己的 DeepSeek Key 时，投研助手会持续显示“固定规则 · 未调用大模型”，输入区给出直达设置的配置入口，回答元信息也会标明固定规则模式。固定规则仍可使用 BaoStock 行情和本地研究能力，但不会冒充大模型对话。回答正文不再重复“本轮 Skill / 执行方式 / 查看依据”三行说明，完整 Trace 仍保留在右侧过程面板和成果文件中。

## 下载

- Apple Silicon Mac（M1/M2/M3/M4 等）：`EquiSeek-macOS-arm64-0.2.0-alpha.5-unsigned.zip`
- Intel Mac：`EquiSeek-macOS-x64-0.2.0-alpha.5-unsigned.zip`
- Windows 10/11 x64：`EquiSeek-Windows-x64-0.2.0-alpha.5-unsigned-Setup.exe`
- 完整性校验：`SHA256SUMS`

## 安装与首次配置

macOS：解压后将 EquiSeek 拖入“应用程序”。首次启动请按住 Control 点击应用并选择“打开”；如果仍被拦截，请前往“系统设置 → 隐私与安全性”确认“仍要打开”。系统仍可能因企业策略禁止未签名软件。

Windows：运行 Setup.exe 后可能看到 Microsoft Defender SmartScreen 警告。确认文件来自本仓库并核对 SHA-256 后，可选择“更多信息 → 仍要运行”。企业管理设备可能禁止绕过。

需要大模型动态语言理解时，在投研助手的无 Key 提示中点击“前往设置配置”，输入用户自己申请的 DeepSeek API Key 并选择“保存并启用”。Key 只保存在当前设备的操作系统安全存储中。

## 安全与使用边界

- 不要从第三方转载站下载；只使用本 Release 的资产。
- 安装前请用 `SHA256SUMS` 核对文件完整性。
- 安装包不包含维护者或用户的 API Key、凭据文件、持仓或决策账本。
- 当前行情研究范围为中国内地 A 股及已支持的境内指数、基金；全球市场尚未接入。
- 本项目是研究与教育工具，不构成个性化投资建议、收益承诺或代客交易服务。
- 详细系统拦截提示与安装步骤见[未签名桌面版安装指南](https://github.com/Bruce7777/EquiSeek/blob/main/docs/installing-unsigned-desktop.md)。
