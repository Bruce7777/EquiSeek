WHAT EQUiSEEK DOES

不是给答案，
是建立一条可信的研究链。

把数据、计算、分析、决策和复盘放在同一个工作台中，每一步都保留可检查的上下文。

01
⌁

投研助手

用自然语言发起研究，组合 Skills、工作区工具与模型能力；没有模型 Key 时明确运行固定规则，不冒充大模型。

  • 持久会话与成果文件
  • Goal、Plan 与运行 Trace
02
⌗

个股研究

本地计算 MA、MACD、KDJ、RSI、ATR、BOLL 与 WR，通过多周期规则给出触发、失效与风险条件。

  • A 股与境内部分指数、基金
  • BaoStock / 可选 Tushare
03
◎

决策账本

把研究结论保存在本机，按同源收盘价跟踪后续变化。结果明确标注为假设复盘，不包装成真实交易业绩。

  • 研究结论随时回看
  • 价格变化同源追踪
04
◇

持仓、自选与 Skills

维护本地持仓、自选和候选标的；查看、启停或扩展研究 Skill，让工作流可以复用，也保持权限边界。

  • 数据默认本地存储
  • 规则与权限可检查

DECISION JOURNAL

结论不是终点，
复盘才是。

求衡将当时的数据截止时间、规则结论、风险分数和逻辑失效条件保存在同一条证据链上。 日后看到的不只是涨跌，而是当初的判断是否成立。

同源研究与后续跟踪尽量使用同一行情来源
透明显示计算依据、时间范围和数据时效
克制等待也是结论，不把风险包装成确定性

KNOW THE BOUNDARIES

研究工具应当说明
它不能做什么。

01

不是券商，也不自动交易

不连接券商、不接受交易委托、不代替用户执行买卖。

02

不是收益承诺

规则结论和模型内容仅作研究参考，可能错误、过时或不适合你的风险承受能力。

03

API Key 由用户自己配置

安装包不内置维护者密钥。未配置 DeepSeek Key 时，仅运行并明确标注本地固定规则模式。

04

当前市场范围有限

目前以 A 股和部分境内指数、基金为主；美股、港股及其他全球资产尚未接入。
