# 多周期 MACD/WR 技术结构

只使用已校验并统一复权的历史 K 线，不让语言模型计算任何信号。

1. 从日 K 按自然周和自然月聚合；形成中的周/月 K 只用于显示，必须从正式 MACD、
   WR、背离和双峰决策输入中排除，并同时记录决策截止日与最新可见日期。
2. 月线、周线、日线 MACD 按 3:2:1 权重判断大方向。
3. 记录零轴位置、金叉/死叉、零轴上多次金叉、价格-DIF 顶背离和 DIF 双峰结构。
4. WR 使用正向 0–100 口径：`WR >= 80` 为超卖、`WR >= 85` 为深度超卖、`WR <= 20` 为超买。
5. 上涨结构且无高周期顶部风险时，日线 WR 进入超卖区标为买入时机输入。
6. 周/月线出现顶部或调整风险且日/周 WR 进入超买区时，标为卖出时机输入。

输出必须包含公式版本、决策截止日期、最新可见日期、各周期证据和形成中周期排除提示。
信号只表示历史规则触发，不代表未来必然走势。
