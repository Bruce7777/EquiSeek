# 官方宏观时效核验

只访问代码白名单内的国家统计局、中国人民银行、国家外汇管理局和财政部官方页面。

必须记录核验时间、页面地址、成功或失败状态、最近识别发布日期和失败原因。页面日期仅用于判断结构化基线是否可能已经落后，不能从网页摘要推导或覆盖结构化指标数值。

发现基线之后的新发布、基线年龄超过门限或完成核验的官方来源不足时，必须阻止历史资产配置、行业建议和宏观叠加用于当前决策。
