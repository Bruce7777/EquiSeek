# 代价/成本转嫁压力观察

1. 分别构建地产—土地财政、财政—公共成本、资本收益—劳动与民企、外部—国内实体四条转嫁链。
2. 每条链必须列出成本来源、传导通道、主要承接者、投资含义和原始指标证据。
3. 同时展示农村收入相对增速、制造业投资等缓冲或反向证据。
4. 总量相关性不能证明因果；链路是求衡基于温铁军理论的工程化假设，不是作者发布的量化公式。
