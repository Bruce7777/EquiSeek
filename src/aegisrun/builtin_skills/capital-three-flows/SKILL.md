# 资本三流工程化分析

1. 流量使用 M2、社融存量和人民币贷款同比，回答资本总量是否充裕，不把货币供给直接等同于股市资金。
2. 流向使用结售汇、涉外收付款以及制造业/民间/政府融资结构，回答资本进入或离开哪些部门。
3. 流速使用货币增速与 GDP、固定资产投资、制造业投资的差作为实体传导代理；必须明确它不是严格货币流通速度。
4. 三项共同映射为风险偏好与行业风格，不能只凭流量宽松判断全市场上涨。
5. 必须说明该评分是求衡对相关论述的透明量化映射，不是卢麒元本人发布的计量公式。
