# 本地持仓技术风险

1. 只读取本机持仓记录和已经由 `multi-timeframe-macd-wr` 生成的信号。
2. 计算市值、浮动盈亏、收益率、建仓后峰值回撤、回本距离、持仓天数、退出优先级和
   下一复核触发，并复用投资决策引擎给出的持有、加仓、减仓或卖出结论。
3. 周/月 MACD 顶背离、零轴上双峰或转弱且 WR 进入超买区时，给出卖出；风险未完成时机确认时给出减仓。
4. 成本、数量、建仓日和备注不得发送给模型，也不得写入 Agent 事件或普通日志；行业
   标签可以形成不含持仓财务信息的宏观映射。
5. 允许输出规则动作和失效条件，不得承诺收益、虚构自动交易或绕过用户复核。
